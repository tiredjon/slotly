## Что такое Slotly

Сервис онлайн-записи: у мастера (барбер, тренер, репетитор) есть рабочие часы и услуги, клиент видит свободные слоты и бронирует. Задача простая по смыслу, но в ней есть всё, о чём спрашивают на собесах: модели данных, REST API, авторизация, бизнес-правила и главное — гонка при бронировании, когда два клиента одновременно хватают один слот.

Если ты задумывал Slotly иначе, скажи. Темы по неделям останутся теми же, поменяются только фичи.

**Что будет в конце, неделя 12:**

| Часть | Что умеет |
| --- | --- |
| API | FastAPI, около 15 эндпоинтов, автодокументация Swagger |
| База | PostgreSQL + SQLAlchemy 2.0, миграции Alembic |
| Авторизация | JWT, две роли: мастер и клиент |
| Надёжность | Двойная бронь невозможна, даже если 2 запроса пришли в одну миллисекунду |
| Тесты | 30+ тестов на pytest |
| Прод | Docker Compose, задеплоено, есть живая ссылка |
